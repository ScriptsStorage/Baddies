# Baddies Script
[Play the game: (https://www.roblox.com/games/11158043705/Baddies)**Baddies**]
A feature-packed Roblox script for **Baddies**, featuring automated farming, combat utilities, visual enhancements, movement options, and various gameplay modifications.

> **⚠️ Disclaimer:** This project is intended for educational and experimental purposes. Using third-party scripts or automation may violate Roblox or game-specific rules and can result in account penalties.

---

## ✨ Features

### 💰 Autofarm

Automate money-making activities with built-in farming features.

* **Nails Farm** — Automatically farms nails for growth.
* **ATM Farm** — Automatically interacts with ATMs to generate money.

---

### ⚔️ Combat

A collection of combat-focused features.

* **Auto Fight** — Automatically engages nearby players.
* **Expand Hitbox** — Enlarges player hitboxes for easier targeting.
* **Kill Person** — Targets a selected player.
* **Auto Grab Hair** — Automatically grabs nearby hair.
* **Auto Stomp** — Automatically stomps downed players.
* **Auto Fight Spam Remote** — Automates repeated combat remote interactions.

---

### 🔧 Mods

Gameplay modification and aiming features.

* **Vehicle Modifications** — Additional vehicle-related modifications.
* **RPG Silent Aim** — Automatically assists RPG targeting.
* **Silent Aim Person** — Automatically assists targeting players.
* **Aim All Flamethrower** — Automatically targets players with the flamethrower.

---

### 👁️ Visuals

ESP and player-information features for improved visibility.

* **Item ESP** — Displays important items.
* **Highlight Player** — Highlights players.
* **Robbery ESP** — Displays robbery-related locations.
* **Tracers** — Draws lines toward players or objects.
* **Money ESP** — Displays money-related objects.
* **Name ESP** — Displays player names.
* **Health ESP** — Displays player health.

---

### 🛠️ Misc

Additional movement and quality-of-life features.

* **Fly** — Enables flying movement.
* **NoClip** — Allows movement through certain objects.
* **Speed** — Modifies movement speed.
* **Teleporting** — Quickly teleport to locations or players.
* **Infinity Jump** — Allows repeated jumping.
* **Anti AFK** — Prevents automatic AFK detection.
